# ADR 0001: 0단계 기술 선택

## 결정
- Python 3.11+, httpx, Pydantic, psycopg 3, Typer
- 재무 수치는 Postgres 에 원 단위 BIGINT 로 저장하고 원본 문자열도 보관
- 원문은 저장소(로컬/MinIO)에 모두 보관
- OpenDART 목록 조회는 `last_reprt_at=Y` 로 최종 보고서만 받는다

## 이유
- 숫자는 LLM 이 아니라 DB 값으로 답하는 것이 서비스의 핵심 정확도 장치이므로, 수집 단계부터 단위와 정정공시를 명시적으로 처리한다
- 원문을 보관하면 파서를 바꿨을 때 API 한도 걱정 없이 전체를 다시 처리할 수 있다
- 해석할 수 없는 금액이나 검증되지 않은 회계연도 규칙은 추측하지 않고 오류나 건너뜀으로 드러낸다
