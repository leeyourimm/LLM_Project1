# ADR 0010: 개인정보 최소 수집과 보관 기간

- 상태: 채택
- 관련 코드: `src/dartrag/worker/jobs.py`(`maintenance`), `src/dartrag/db/repository.py`(`delete_user`, `export_user`, `purge_*`), `src/dartrag/web/app.py`(`/api/account`), `frontend/src/app/privacy/page.tsx`

## 맥락
- 서비스는 공개 공시만 다루지만, 사용자 계정·관심 종목·알림 주소·질문 기록은 개인정보다. 관심 종목과 질문은 투자 성향을 드러낼 수 있다.
- 수익을 내지 않는 서비스라 데이터를 오래 쌓아 얻는 이득보다 유출 시 피해가 크다.
- 개인정보처리방침이 "탈퇴와 내 정보 열람을 직접 할 수 있다"고 약속한다.

## 결정
- **최소 수집**: 가입에 이메일과 비밀번호만 받는다. 비밀번호는 scrypt 해시, 세션 토큰·인증 코드는 SHA-256 해시로만 저장한다. 이름, 전화번호, 접속 IP 는 DB 에 저장하지 않는다 (IP 는 로그인 시도 제한에 메모리에서만 잠깐 쓴다).
- **외부 전송 최소화**: 답변 모델과 LLM 추적은 서버 안에서 처리하고(ADR 0002, 0009), 오류 보고는 개인정보를 지운 뒤에만 보낸다.
- **보관 기간**: 대화 기록은 마지막 사용 후 180일(`CONVERSATION_RETENTION_DAYS`), 만료된 세션은 바로, 알림 발송 기록과 작업 기록은 90일 뒤 새벽 정리 작업이 지운다.
- **탈퇴와 열람**: 계정 화면에서 지금 비밀번호를 확인하고 바로 탈퇴한다. 사용자 기록이 든 모든 표를 한 트랜잭션에서 지우고, 외래 키도 `ON DELETE CASCADE` 로 둔다. 운영자 명령 `dartrag user remove` 도 같은 경로를 쓴다. "내 데이터 내려받기"는 계정, 관심 종목, 알림 설정, 발송 기록, 질문·답변과 평가를 JSON 으로 주되 비밀번호 해시·세션·인증 코드는 넣지 않는다.

## 결과와 트레이드오프
- 유출되더라도 비밀번호, 로그인 상태, 인증 링크는 복원할 수 없다.
- 오래된 대화를 다시 볼 수 없고, 👎 평가가 달린 대화도 180일 뒤 사라지므로 평가셋으로 옮길 것은 그 전에 내보내야 한다.
- DB 백업 사본, Langfuse 추적, 서버 로그에는 탈퇴 뒤에도 기록이 남을 수 있다. 백업은 30일 안에 순환시키고 Langfuse 보관 기간을 따로 설정해야 한다 (docs/security-review.md 남은 위험).
- 이메일 소유 확인 없이 가입할 수 있어, 남의 이메일로 가입하는 것을 막지 못한다 (알림 메일은 인증 링크를 연 뒤에만 보낸다).
